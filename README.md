# 株式会社アマテック | 未来を、実装する。

私たちは、Webサービスからロボティクスまで、**「ちゃんと使われる技術」**をつくる開発チームです。課題の整理から設計・実装・検証・運用まで、現場で動く形にすることを大切にしています。

## What we build

- **Web・SaaS** — 使いやすさと事業の成果を両立するサービスやアプリを開発しています。コーポレートサイトでは Astro・TypeScript、API では Node.js を使用しています。
- **ロボティクス・フィジカルAI** — NVIDIA Isaac Sim と ROS 2 を用いた Sim-to-Real に取り組み、シミュレーションから実機での動作検証まで進めています。

## Languages & frameworks

- **Web** — TypeScript・JavaScript、Astro。React を組み合わせた Web 制作も[技術記事](https://ama-tec.jp/tech/zw7p036tym0q98k23e1d/)で紹介しています。
- **バックエンド** — [コーポレートサイトの API](https://ama-tec.jp/tech/51zcnu9fi2xs6pdnbmmg/)では Node.js を使用。採用ページでは Go・Node.js・Python の経験を募集し、Gin・Ent を歓迎スキルとして挙げています。
- **ロボティクス** — [採用ページ](https://ama-tec.jp/recruit/)では Python・C++ を対象とし、[技術検証](https://ama-tec.jp/tech/sj8o6wb9f1i0mik0iamr/)では ROS 2・NVIDIA Isaac Sim を使用しています。

## リポジトリ構成と品質の考え方

- **モノレポ** — 全社的なモノレポ運用、採用ツールやディレクトリ構成は公開情報からは確認できていません。
- **Web** — [技術記事](https://ama-tec.jp/tech/zw7p036tym0q98k23e1d/)では型安全性と保守性、[採用情報](https://ama-tec.jp/recruit/)では UI の使いやすさ・アクセシビリティ・表示性能を重視しています。
- **ロボティクス** — シミュレーション上の動作だけでなく、実機との挙動差や同期・制御を[実機検証](https://ama-tec.jp/tech/sj8o6wb9f1i0mik0iamr/)で確かめています。
- **レビュー** — 仕様判断は人間が担い、AI は境界条件・例外ケース・テスト観点の洗い出しを[支援](https://ama-tec.jp/tech/openclaw-development-workflow/)します。テストの必須範囲やカバレッジ閾値は公開情報では確認できていません。

## How we work

- **つくって、動かして、改善する。** UI の使いやすさや性能、ロボットの実機との挙動差まで確かめながら開発します。
- **判断は人間、AI は支援役。** 課題整理や PR レビューにも AI を活用しつつ、目的・仕様・優先順位の判断は開発メンバーが担います。
- **知見を公開する。** 技術検証や開発プロセスで得たことを[技術記事](https://ama-tec.jp/tech/)にまとめています。
